# Seguridad

## Versiones compatibles

Las correcciones de seguridad se aplican a la rama por defecto del repositorio.

## Reportar una vulnerabilidad

No publiques vulnerabilidades ni secretos en issues públicos, pull requests o
comentarios.

Envía un aviso privado a los mantenedores mediante el canal privado disponible
para el repositorio en GitHub (Security Advisory). Incluye:

- versión o commit afectado;
- descripción y impacto;
- pasos reproducibles;
- evidencia o pruebas mínimas;
- posibles medidas de mitigación.

Los mantenedores pueden pedir información adicional antes de publicar o corregir
el aviso.

## Datos sensibles

No añadas contraseñas, claves, tokens, certificados privados, bases SQLite con
datos reales ni adjuntos reales al repositorio. Usa `.env.example` y datos
sintéticos en tests.
