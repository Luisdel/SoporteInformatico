# Código de conducta

## Compromiso

Las personas que participan en este proyecto se comprometen a mantener un entorno
respetuoso, profesional y abierto a nuevas aportaciones.

## Conducta esperada

- Trata a las demás personas con respeto y buena fe.
- Critica ideas y código, no a las personas.
- Aporta información suficiente y reproducible al reportar problemas.
- Respeta distintos niveles de experiencia y antecedentes.
- Protege datos personales y evita publicar secretos o información sensible.

## Conducta no aceptable

No se permite acoso, insultos, amenazas, discriminación, lenguaje degradante,
coerción ni publicación deliberada de información privada o credenciales.

## Aplicación

Los responsables del repositorio pueden solicitar cambios de conducta, cerrar
conversaciones o retirar aportaciones que incumplan estas normas. Las decisiones
se tomarán de forma proporcional y buscando preservar un entorno seguro para
contribuir.
